### GitHub API Copilot
*A documentation assistant that cites its sources, or admits it doesn't know.*

- Answers GitHub REST API questions from the official OpenAPI spec, with a citation on every answer
- Hybrid retrieval: keyword (BM25) plus semantic search, merged for better recall
- Scored on a hand-verified 105-question set: right source in the top 5 results on **99 of 105**, and **94.3%** of answers stay grounded in what it retrieved

### Workflow Engine
*Automation that recovers from failure.*

- Describe a workflow as a graph of steps; the engine orders them, rejects circular dependencies and runs them
- Failed steps retry with backoff; every run is logged to Postgres
- First workflow: scans five job boards for internships, removes duplicates and alerts me on Telegram
- 46 automated tests, CI on every pull request
